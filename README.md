# Mount Arayat Tourism Website 

## About the Project

The Mount Arayat Tourism Website is a simple and informative website created to introduce the beauty, tourist attractions, and hiking trails of Mount Arayat in Pampanga, Philippines.

This website helps visitors learn more about Mount Arayat, explore its tourist destinations, understand the available hiking trails, and find important visitor information. It also provides a contact and inquiry form for people who are interested in visiting or hiking the mountain.

## Website Features

- Home – Introduces Mount Arayat and highlights some tourist attractions.
- About & Trails – Provides information about the mountain, its history, and available hiking trails.
- Interactive Trail Explorer – Allows visitors to explore the North Peak, South Peak, and Twin-Peak Traverse.
- Contact & Register – Provides visitor information and a form for hike inquiries.
- Location Information – Shows the jump-off points for hiking trails.
- Responsive Design – Supports desktop and mobile screen sizes.
- Easy Navigation – Simple navigation buttons for a better user experience.

## Technologies Used

- HTML5 – For the website structure.
- Tailwind CSS – For styling and layout.
- JavaScript – For interactive features and navigation.
- Font Awesome – For icons.
- Google Fonts – For website typography.

## Purpose of the Website

The purpose of this website is to promote Mount Arayat as a tourist destination and provide visitors with accessible information about its natural beauty, attractions, hiking trails, and visitor guidelines.

## Target Users

- Tourists and visitors
- Hiking enthusiasts
- Nature lovers
- People interested in exploring Pampanga

## Project Location

Mount Arayat, Pampanga, Philippines
